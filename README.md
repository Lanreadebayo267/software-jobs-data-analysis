# Software Jobs Data Analysis

## Overview

This software analyzes a dataset of data science jobs using Python, Pandas, and Matplotlib. It demonstrates how data analysis techniques can be used to identify employment trends, salary information, experience levels, and remote work patterns.

The purpose of this project is to practice loading, cleaning, analyzing, and visualizing data using Python while applying programming concepts learned in CSE 310.
